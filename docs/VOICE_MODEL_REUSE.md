# Повторное использование моделей в v4

## Воспроизведение прежнего бага

1. В «Дневнике мыслей» открыть голосовой ввод первого вопроса и загрузить Whisper Tiny.
2. Дождаться готовности и открыть голосовой ввод другого вопроса.
3. Прежний `Dictation` заново показывал текст про первую загрузку и кнопку подготовки: он не проверял общий `Cache Storage`, хотя файлы оставались в браузере.

## Исправление

- Все поля диктовки используют тот же проверяемый кэш Whisper, что и компонент голосового сообщения. Наличие модели определяется по всем необходимым файлам закреплённой ревизии, без флага «скачано» в localStorage.
- При открытии поля сохранённая модель запускается автоматически из кэша. Запуск модели в новом worker не означает повторное скачивание весов. Микрофон включается только отдельной кнопкой пользователя.
- `useModelCache` использует общий внешний store для каждого проверяющего адаптера. Одновременные проверки полей объединяются, а завершённая загрузка уведомляет другие поля. Запоздалая проверка до загрузки не может затереть новый результат.
- Во время первой проверки показывается «Проверяем модель…», а не ложное предложение скачать. Статусы Whisper, GigaAM-Emo и Qwen обновляются после загрузки и возврата фокуса.
- Общими являются только сведения о публичных файлах модели. Аудио, расшифровки, промпты, результаты пациентов и worker с содержимым не разделяются между полями или аккаунтами. Закрытие диктовки останавливает её worker и микрофон.
- Запрашивается сохранение браузерного хранилища. Если браузер отказал, очистил данные сайта, удалил файлы при нехватке места либо открыта другая версия модели/другой origin, повторная загрузка действительно может понадобиться. Это не скрывается постоянной отметкой «скачано».

## Проверки

`tests/model-cache.mjs`: полный/частичный кэш, новая страница, ревизия модели, удалённые файлы, недоступное хранилище, объединение проверок, перемонтирование полей, уведомление о загрузке и гонка запоздалой проверки.

Ручная проверка в локальном браузере: реальная загрузка Whisper, готовность первого поля, автоматическое чтение сохранённой модели во втором, перезагрузка страницы и запуск третьего поля. Настоящие аудио и разрешение микрофона для этой проверки не требуются.
